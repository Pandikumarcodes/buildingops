`fallback.svg`: project-created commercial-building illustration. Used when a photo fails. Unknown codes receive the shared generic commercial photograph. If the illustration also fails, a text placeholder remains.

Images are illustrative; they do not depict an actual monitored BuildingOps site. Demo code mapping is deterministic and independent of list order or display name. No remote image requests occur at runtime.
